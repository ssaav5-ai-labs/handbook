# 2026-10-23: Playbook 01 - GitHub organization and publish handbook

## Goal
Run `playbooks/01-github-foundation` to set up the lab GitHub org like a company's, push the handbook, and publish its site.

## What I did
- **Step 1 (names):** The org `ssaav5-ai-labs` already existed (created 2026-10-22), so the "name free / 404" check was already satisfied and step 2 was skipped. Custom domain: **later** (unchanged from the open-question leaning).
- **Step 2 (create org):** Already done — 2FA requirement `true`, base permission `read` on the Free plan.
- **Step 3 (repo + push):** Pushed `handbook` to `main` (public) and created empty `workstation` (public) and `career-vault` (private, under `ssaav5`). `workstation` and `career-vault` local history still needs pushing from Windows (🧑).
- **Step 4 (org settings):** Created teams `sre` and `platform`; added `.github/CODEOWNERS` assigning `docs/decisions/` and `docs/open-questions/` to `@ssaav5-ai-labs/sre`.
- **Step 5 (ruleset):** Created a **repository-level** ruleset `protect-main` on the handbook (`main`): PR required, `build` status check required, force-push/deletion blocked, linear history, bypass list empty, `current_user_can_bypass: never`.
- **Step 6 (security):** Enabled Dependabot alerts, Dependabot security updates, secret scanning and push protection.
- **Step 7 (publish):** Set Pages to deploy from GitHub Actions (`build_type: workflow`); site URL `https://ssaav5-ai-labs.github.io/handbook/`.

## What broke and how I fixed it
- **Org-level rulesets unavailable on Free plan:** `gh api orgs/ssaav5-ai-labs/rulesets` returned *"Upgrade to GitHub Team"*. Fix: create a **repository-level** ruleset instead (free on public repos, same effect). Playbook step 5 updated in this PR.
- **Secret-scanning enable endpoints 404:** `PUT repos/.../secret-scanning` and `POST .../secret-scanning/push-protection` returned 404 (those routes are for private repos). Fix: `PATCH repos/ssaav5-ai-labs/handbook` with a `security_and_analysis` body, which set `secret_scanning` and `secret_scanning_push_protection` to `enabled`.

## Decisions made (link ADRs)
- Accepted ADRs 0001-0006 (record-as-ADRs, markdown-in-git, central handbook, free org/public repos, private career vault, local repo layout). ADRs 0007-0009 remain `proposed` (covered by other playbooks).
- Custom domain deferred; `ssaav5-ai-labs.github.io/handbook` is the canonical URL for now.
