# 2026-10-20: Knowledge system and GitHub plan

## Goal
Decide how to capture everything from the homelab build so it serves humans, AI agents, future roles and public posts.

## What I did
- Compared Obsidian, OpenKnowledge, Outline, Wiki.js/BookStack and docs-as-code; verified MCP claims against current sources.
- Chose Markdown + frontmatter in Git as the store, with a central handbook repo and a private career vault.
- Planned a free GitHub organization with public repos to practice enterprise governance.

## Decisions made
ADR-0001 through ADR-0006 (proposed).

## Next
