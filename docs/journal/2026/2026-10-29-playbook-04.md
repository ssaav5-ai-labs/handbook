# 2026-10-29: Playbook 04 - Argo CD, SOPS and age

## Goal
Run the cluster from Git with a slim, self-managed Argo CD, secrets encrypted with SOPS and age, decryptable by KSOPS in-cluster.

## What I did
All 11 steps completed — see step-by-step entries above.

## What broke and how I fixed it
- shellcheck SC1091 — added `-x` flag to follow sourced files.
- kubeconform CRDs-catalog didn't have Argo CD CRD schemas — switched to `-ignore-missing-schemas`.
- `check-secrets.sh` used `head -5` which missed the `sops:` block deeper in encrypted files — changed to `grep -q '^sops:'`.

## Decisions made (link ADRs)
- [ADR-0019](../../docs/decisions/0019-gitops-with-argo-cd-app-of-apps.md) — accepted (GitOps with Argo CD app-of-apps).
- [ADR-0020](../../docs/decisions/0020-secrets-in-git-with-sops-age-ksops.md) — accepted (secrets in Git with SOPS + age + KSOPS).
