# 2026-10-22: Playbook 00 - workstation and knowledge capture

## Goal
Run `playbooks/00-workstation-knowledge` to set up the workstation and start capturing knowledge from day one.

## What I did
- **Step 1 (names):** Confirmed `github.com/ssaav5-ai-labs` is still unclaimed (`curl` returns 404). GitHub username is `ssaav5`. ADR-0011 already covers the org name; nothing new to record.
- **Step 2 (permanent place):** Handbook moved to `$env:USERPROFILE\code\github.com\ssaav5-ai-labs\handbook` and the dev container was re-upped from there (done before this session). Matches ADR-0006.
- **Step 3 (version control):** `git init -b main`, repo-local identity `ssaav5 <59281710+ssaav5@users.noreply.github.com>` (no-reply address per recommendation), first commit `b33b555`, amended to `91c4c91` after fixing file modes.

## What broke and how I fixed it
- **Git ownership error:** `git add` failed with "detected dubious ownership in repository" (container user owns a root-mounted workspace). Fixed with `git config --global --add safe.directory /workspaces/handbook`, then everything proceeded.
- **Wrong file modes in first commit:** Files were committed `100755` because the workspace mount made everything look executable. Fixed by `git config core.fileMode false`, `git config core.autocrlf input`, `git ls-files -z | xargs -0 git update-index --chmod=-x`, re-adding executable bit only for `scripts/sync-skills.sh`, and amending the initial commit. Verified via `git ls-files -s`: only `scripts/sync-skills.sh` is `100755`.

## Decisions made (link ADRs)

- Repo layout per ADR-0006; commits use GitHub no-reply email (keeps personal email out of a future public repo).
